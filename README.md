# BiosenseSignal SDK — Sample Apps

This repository contains sample applications demonstrating how to integrate and use the BiosenseSignal SDK across multiple mobile platforms.

The SDK enables contactless measurement of vital signs (heart rate, respiration rate, oxygen saturation, and more) using the device camera.

## Platforms

| Platform | Path |
|----------|------|
| Android (Kotlin) | [`android/kotlin`](android/kotlin/README.md) |
| Android (Java) | [`android/java`](android/java/README.md) |
| iOS (Swift) | [`ios`](ios/README.md) |
| Flutter | [`flutter`](flutter/README.md) |
| React Native | [`react-native`](react-native/README.md) |

## SDK Access

The BiosenseSignal SDK is distributed via a private Artifactory registry. To build any of the sample apps you need valid Artifactory credentials:

| Credential | Description |
|------------|-------------|
| `ARTIFACTORY_USERNAME` | Your Artifactory username |
| `ARTIFACTORY_API_KEY` | Your Artifactory API key or identity token |

Contact [support@biosensesignal.com](mailto:support@biosensesignal.com) to obtain access.
